The chosen composite — A base + B controls + all of C

FULLY DECIDED 2026-08-04/05 — the functional blueprint: A base · compact SIX-chip strip (exact partition: טיוטות + גלויים + מתוזמנים + חסומים = הכל, plus מוצמדים as a window) · grouping + sort toggles · open filter panel above the table (EQ-7 flip) · inline status select · clickable date cell · remedy doors · podcast group headers · only the title column fixed, all else in the column manager · default sort עודכן לאחרונה. Navigation: episodes ungrouped on top; «ניהול תוכן» (podcasts + transcriptions) collapsed and moved BELOW «ניהול סיווג»; transcriptions item hidden in single mode for non-super-admins; dashboard stays the landing; labels unchanged. Model rules: publish stamps a null published-date (never overwrites, all status+date models); a central effective-published-date resolver falls back to created_at for published rows with null dates (read-side accessor + COALESCE sort scope — no backfill). Policy: ContentItemPolicy with delete = super-admin only. Principles P-EL1–P-EL8 ratified. The two boards below are the two REALIZATIONS of this blueprint — pick one or phase 1→2.
