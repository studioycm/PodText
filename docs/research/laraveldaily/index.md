Generated by `build-index.mjs` — **407 lessons** across **27 courses**.

Enriched from `raw/` (**27** courses scraped): sizes, counts and the API identifiers each lesson actually mentions.

## How to use it

One line per lesson, every searchable term on that line — so grep returns the
lesson, not a heading you then have to read around.

```bash
grep -i "observer"  docs/research/laraveldaily/index.md   # by concept
grep -i "ofMany()"  docs/research/laraveldaily/index.md   # by API identifier
grep -i "2026"      docs/research/laraveldaily/index.md   # by recency
grep -i "filament"  docs/research/laraveldaily/index.md   # by course/subject
```

Columns per row: `course` · `released` · `format` · size · links · comments ·
transcript · identifiers. `**TRUNCATED**` marks a body that is both unterminated
*and* well under its course median — the shape of a paywall teaser. A body merely
ending in a code block is not flagged.

**Freshness still applies.** A row being listed says nothing about whether its
advice is current — see [README](README.md) §2, especially the rule that lessons
older than Laravel 12 need their *pattern* checked, not just their APIs.
